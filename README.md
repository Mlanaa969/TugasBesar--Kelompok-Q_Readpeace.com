# TugasBesar--Kelompok-Q_Readpeace.com
Aplikasi manajemen relawan RedPeace.com menghubungkan relawan dan kegiatan sosial (relasi banyak-ke-banyak) dengan penugasan berbeda tiap kegiatan. Relasi dikelola dengan Multi Linked List, dokumentasi laporan aktivitas setelah kegiatan dicatat dalam Binary Search Tree, dan keduanya terhubung ke data relawan serta kegiatan.
